Step 1 of 6

Import laboratory data

What are we doing?
Bringing in your triaxial tests and confirming what each column means.
Why are we doing it?
Every test is converted to the same variables NorSand produces, so lab and model curves can be compared directly.

Missing quantities are calculated where possible, so you only need to provide enough columns to describe each test.

Step 3 of 6

Critical state line

What are we doing?
Choosing the points where each test truly reached critical state, then fitting the CSL through them.
Why are we doing it?
The CSL defines the state parameter ψ, and every NorSand parameter after this depends on it.
ψ = e − ec(p′)

Select or confirm the critical-state point for each test. Accepted points are used to fit the line.

Select and confirm critical-state points

A test that ends at 20% strain has not necessarily reached critical state. Accept a point only when q, p′ and the volume or pore pressure have stopped changing, and the dilatancy D is close to zero.

Step 4 of 6

Plasticity calibration

What are we doing?
Dense drained tests are used to determine the relationship between stress ratio, dilatancy and state.
Why are we doing it?
The maximum-dilation condition from each test is used to estimate Mtc, N and χtc.
η = q/p′    D = dεvp / dεqp    εq = ε1 − εv/3

The state parameter is calculated at every data point using the CSL from step 3. Each dense drained test then gives one maximum-dilation point.

  1. Lab data
  2. Calculate e
  3. CSL gives ec
  4. Calculate ψ
  5. Identify maximum-dilation points
  6. Fit Mtc, N and χtc

Step 5 of 6

Stiffness and hardening

What are we doing?
Running NorSand for each test and adjusting Gref, H0 and, only if needed, Hy until the curves match the lab data.
Why are we doing it?
Stiffness and hardening cannot be read off a plot, so they are found by comparing the model with the measured response.

The model reruns every time a parameter changes. Type an exact value in a box, or drag its slider to see how sensitive the fit is. OCR is not calibrated here. Each test uses the OCR entered in step 1.

a. Starting stiffness, Gref
Method

E ≈ 2000 NSPT = – kPa
G = E / [2(1 + ν)] = – kPa
Gref = G (pref/p′)m

This is only a starting estimate. Refine Gref against the laboratory stress–strain response.

b. Initial hardening, H0

State-dependent hardening is initially disabled (Hy = 0), so H = H0. Adjust H0 to improve agreement between the laboratory data and the NorSand simulation.

For a semi-log CSL, a starting value is H0 ≈ 4/λ. Suggested from step 3: fit the CSL first

c. State-dependent hardening, Hy

Check the fit across tests with different initial state parameters. Only if a single H0 cannot match them all, include Hy and calibrate H0 and Hy against several tests at once.

Validation and export

What are we doing?

Why are we doing it?
A calibration is only useful if a single set of soil parameters describes all the tests reasonably well.

All tests are shown with one parameter set, not one set per test.
