2. Core concepts

2.9 Limiting dilatancy and the internal cap

Without a limiting condition, NorSand could predict unrealistically large dilation for states that are denser than critical state. NorSand therefore imposes a limiting-dilatancy condition linked to the soil state. In triaxial compression, the state–dilatancy parameter χtc, together with the state parameter evaluated at the image condition, determines the limiting image pressure pi,max⁡′. This limits the maximum size to which the outer NorSand yield surface can expand for the current soil state. This limiting condition is commonly described as an internal cap because it restricts the admissible extent of the outer yield surface. It is not an additional external failure envelope. In the present visualizations, users can observe the current stress state, image point, limiting image condition, and the evolution of the current and limiting image pressures with axial strain.
