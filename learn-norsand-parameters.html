2. Core concepts

2.13 NorSand parameters

Implementing NorSand requires a set of material parameters that describe the soil’s critical-state line, strength, plastic response, limiting dilatancy, and elastic stiffness. Many of these parameters correspond directly to the concepts introduced earlier. The CSL parameters define the position and shape of the critical-state line. The strength and plasticity parameters control the stress ratio, dilatancy, and evolution of the yield surface. The elastic parameters control the recoverable part of the response and the initial stiffness.

These parameters are not usually calibrated one at a time from a single test. Instead, they are determined together from a set of drained and undrained triaxial tests covering different initial densities and confining stresses. A reliable parameter set should reproduce the CSL, stress-strain response, volumetric response, and pore-pressure response consistently across the available tests.

The table below summarizes the main NorSand parameters and their roles. The specific values used in the interactive simulations are provided in the following Simulation Parameters section.

Group Parameter Role in the model
Critical state Γ Reference void ratio defining the position of the semi-logarithmic CSL
λ or λ10 Slope of the CSL in e−lnp′ or e−log10p′ space
Ca, Cb, Cc Parameters used when the CSL is represented using a curved form
M or Mtc Critical-state stress ratio in triaxial compression. It defines the stress ratio approached at critical state
Plasticity/stress dilatancy N Controls part of the NorSand stress-dilatancy relationship and affects how plastic volumetric strain develops during shearing.
Plasticity/hardening H, H0, Hy Control how quickly the image pressure and yield surface evolve during plastic loading
Plasticity/limiting dilatancy χtc Controls the state-dependent limiting dilatancy and the limiting image condition
Plasticity/additional softening S Optional softening parameter, mainly used for additional softening in undrained loading of loose soils
Elasticity Gref Reference elastic shear modulus used to define pressure-dependent stiffness
m Exponent controlling the change in elastic stiffness with mean effective stress
Ir Rigidity index, often expressed as G⁄p′
ν Poisson’s ratio, used to relate elastic shear and volumetric stiffness
Initial conditions e0 or ψ0 Initial void ratio or initial state parameter used to define the starting state of the specimen
OCR Over-consolidation ratio used to initialize the yield surface size
