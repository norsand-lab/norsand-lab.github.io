2. Core concepts

2.5 State parameter

The state parameter is one of the most important concepts in NorSand. It was introduced by Been and Jefferies (1985) and is defined as

ψ=e−ec(p′)

It measures the vertical distance between the current state of the soil and the critical state line at the same mean effective stress. When ψ>0, the current void ratio is greater than the critical void ratio. The soil is looser than the critical state at the same effective stress; such a state generally has a stronger tendency to contract during shearing. When ψ<0 the current void ratio is smaller than the critical void ratio. The soil is denser than the critical state at the same effective stress; such a state generally has a stronger tendency to dilate during shearing. At critical state, ψ=0. The state parameter is useful because it combines density and effective stress in one quantity. Two specimens with the same void ratio may behave differently because they are subjected to different effective stress levels — their state parameters reveal this difference. For an initial mean effective stress p0′, the initial state is defined by

ψ0=e0−ec(p0′)

or equivalently,

e0=ec(p0′)+ψ0.
