3. Interactive Simulations

3.3 Validation

The interactive simulations on this website are generated using a MATLAB material-point implementation of NorSand for conventional axisymmetric triaxial compression. The implementation was checked against four GeoStudio/Excel-VBA NorSand benchmark cases using the main response plots: q−ε1, p′−q, εv−ε1, and, for undrained loading, Δu−ε1.
